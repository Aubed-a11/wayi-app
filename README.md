# WAYI - application mobile (Flutter)

Une seule appli pour les clients, les restaurants et les livreurs de WAYI (livraison de repas au Bénin).
Le code est dans `mobile/` (voir `mobile/LISEZ-MOI.txt`).

La compilation Android se lance dans l'onglet **Actions** > « Appli Flutter WAYI ».
L'APK est à télécharger en bas de la page d'exécution (Artifacts).
